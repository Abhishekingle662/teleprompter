# How to Use Your New Script in the Teleprompter App

## Your New Script: new_script.txt

I've created a professional presentation script for you. Here's how to use it:

### Method 1: Import the File (Recommended)
1. Launch the Teleprompter app using `npm run tauri dev`
2. In the Controls Panel, find the "Text" section
3. Click the **"Import File"** button
4. Navigate to and select `new_script.txt`
5. The script will load automatically!

### Method 2: Copy and Paste
1. Open `new_script.txt` in any text editor
2. Copy all the text (Ctrl+A, Ctrl+C)
3. In the Teleprompter app, paste it into the text area

### Method 3: Save as a Profile
After loading the script, you can save it as a profile for easy access:
1. Load your script using Method 1 or 2
2. Adjust your settings (font size, speed, etc.)
3. Click **"Save Profile"** in the Profiles section
4. Give it a name like "Presentation Script"
5. Now you can quickly reload this script and settings anytime!

## Recommended Settings for This Script

For a professional presentation:
- **WPM:** 140-160 (moderate pace)
- **Font Size:** 60-80px (readable from distance)
- **Font Family:** Georgia or Verdana (clean, professional)
- **Countdown:** 3-5 seconds (time to get ready)
- **Focus Band:** Enabled at 50% position

## Tips for Best Results

1. **Practice First:** Run through the script at your chosen speed before the actual presentation
2. **Use Keyboard Shortcuts:** Ctrl+Space to play/pause, Ctrl+Up/Down to adjust speed on the fly
3. **Mirror Mode:** Enable if using with a teleprompter glass setup
4. **Save Your Session:** Click "Save Session" to preserve your position if you need to pause

Enjoy your presentation! 🎤
